- 架構原有 SQLite、sqlite3、資料檔 volume 與檔案鎖設計已於步驟 0 同步為 PostgreSQL；後續據此實作，不開發 SQLite 儲存路徑。

## 2. 開始前的相依條件

| 項目 | 何時需要 | 缺少時可繼續的工作 |
|---|---|---|
| PostgreSQL 版本、host、port、database、schema、專用帳號與有效憑證 | 步驟 3 的資料庫整合前 | 專案骨架、CSV 與離線計算測試 |
| App container 到既有 PostgreSQL container 的網路路徑 | 步驟 3 連線測試及步驟 7 部署前 | 離線模組及固定資料測試 |
| 公司 CA 與受攔截來源的設定 | 步驟 4／5 串接相關官方清單及報價來源前 | 離線映射及 Provider 固定回應測試 |
| Finnhub 免費金鑰、帳號權限與實際額度 | 步驟 5 的 Finnhub 實測前 | 已完成單次真實抓價及 rate-limit header 查核；長時間額度行為於步驟 9 觀測 |
| 完整代表標的名單、估值來源及驗收門檻 | 步驟 9 正式觀測前 | 功能開發與探索性取樣 |

連線密碼與 API Key 透過執行環境注入，不寫入文件、版本控制、映像或測試證據。尚缺的設定於對應步驟補齊，不要求在離線開發前全部取得。

- 依步驟 0 → 10 推進；測試隨模組完成，不延到最後一次執行。資料庫、金鑰或觀測窗口尚缺時，可先完成不依賴它們的離線工作。
